SADLER FAMILY ARCHIVE - SHAREABLE SITE
======================================

WHAT'S IN THIS FOLDER
  index.html ... review.html   the seven pages of the site
  assets/data.js               ALL family data lives here - edit this to add people
  assets/style.css, app.js     look & behaviour (shared by every page)
  photos/                      drop photos here (see photos/PHOTO-GUIDE.txt)

TO VIEW IT
  Open index.html in any browser. Everything works offline.

TO SHARE IT
  Option 1 - send the folder: zip it and email/WhatsApp it. The recipient
             unzips and opens index.html.
  Option 2 - put it online (free, no coding):
             * netlify.com -> "Deploy manually" -> drag this folder in.
               You get a link like sadler-family.netlify.app to send around.
             * or GitHub Pages if you use GitHub.

TO UPDATE IT
  All names, dates and relationships are in assets/data.js.
  Photos: just drop correctly-named JPGs into photos/ - nothing else needed.

ABOUT THE DATA
  Woven from three sources: the MacFamilyTree master database (2013-16),
  the 2026 family document, and oral-history notes. Conflicts are NOT
  silently fixed - see the Data review page for every open question.
